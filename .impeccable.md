## Design Context

### Users
Equipo interno y personas a las que se les enseña el sistema (demo del CMS).
Entran para ver cómo queda una web gestionada con MoixCMS y cómo funciona el
flujo panel → Git → build → publicación. Lo abren tanto en portátil como en
el móvil (enlaces compartidos por chat).

### Brand Personality
Técnico, preciso, sereno. Una herramienta bien hecha que no necesita gritar.
Debe transmitir confianza y orden; el humor lo pone el contenido (lo escribe
el equipo), no la interfaz.

### Aesthetic Direction
- Tema oscuro, neutros tintados hacia el azul marino de las ilustraciones
  (hue ~265). Nada de negro ni blanco puros.
- Acento cálido tipo "señal de instrumento" (ámbar), usado con moderación:
  página actual, botones, foco. Evitar la paleta cian/morado con brillos.
- Tipografía: Archivo (títulos, navegación, marca) + Atkinson Hyperlegible
  Next (texto). Números tabulares para índices ("01", "02"…), como en el
  diagrama de "Cómo funciona".
- Detalles precisos: líneas de 1px, indicadores alineados a los bordes,
  movimiento corto con easing exponencial y respeto a reduced-motion.
- Anti-referencias: plantillas SaaS con glassmorphism, gradientes en texto,
  tarjetas dentro de tarjetas, iconos redondeados sobre cada título.

### Design Principles
1. Precisión antes que adorno: cada línea, espacio y color tiene una razón.
2. El contenido lo edita gente no técnica: los componentes deben aguantar
   títulos largos, muchas páginas o secciones vacías sin romperse.
3. Móvil de primera: objetivos táctiles ≥ 44px, una sola línea de cabecera,
   nada importante escondido.
4. Accesible por defecto: contraste AA, foco visible, navegación por teclado,
   `aria-current`, `prefers-reduced-motion`.
